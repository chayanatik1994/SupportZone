1.What is JSX, and why is it used?
Answer : JSX stands for JavaScript XML.  It resembles HTML but is utilized within JavaScript.  
 It allows you to create UI elements that are simple to read and write by mixing JavaScript and HTML-like syntax.  

 2.What is the difference between State and Props?
 Answer : State*is data that belongs to a component and can vary over time (similar to a counter value).  
 Props (short for properties) are data that is sent from a parent component to a child component. 

 3 What is the useState hook, and how does it work?
 Answer : The 'useState' method (hook) in React allows you to add state to a functional component.  
It returns two items:  The current state value and   
A function for updating that state.  
4.How can you share state between components in React?
Answer : Lifting state: Move the shared state to a common parent component and transmit it down to child components using props.
5.How is event handling done in React?
Answer : Event names are written in camelCase (e.g., onClick instead of onclick).
